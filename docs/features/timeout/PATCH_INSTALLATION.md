# How to Manually Apply the Timeout Feature

If you need to use the timeout feature before the official release (v0.29.0) is merged, you can apply it as a patch to your existing ShellSpec installation.

## Prerequisites

- `curl` or `wget`
- `patch` utility (standard on most Unix-like systems)
- Access to your ShellSpec installation directory (e.g., `~/.local/lib/shellspec` or wherever it was cloned/extracted)

## Quick Installation (Recommended)

### Option 1: Using Release-Based Patch (Clean Apply)

This patch was generated by comparing the actual 0.28.1 release with the new version, so it applies cleanly:

```bash
# Navigate to your ShellSpec installation
cd ~/.local/lib/shellspec  # or wherever shellspec is installed

# Download the release-based patch
curl -L https://raw.githubusercontent.com/OleksandrKucherenko/shellspec/timeout-implementation/docs/features/timeout/shellspec-0.28.1-to-0.29.0-timeout.patch -o timeout.patch

# Apply the patch
patch -p1 < timeout.patch

# Verify installation
./shellspec --help | grep timeout
```

**Expected output:**
```
--timeout SECONDS           Specify the default timeout for each test [default: 60]
--no-timeout                Disable timeout for all tests
```

### Option 2: Using PR Patch (May Have Rejections)

```bash
# Download patch for PR #357 (Release 0.29.0)
curl -L https://github.com/shellspec/shellspec/pull/357.patch -o shellspec-timeout.patch

# Apply the patch
patch -p1 < shellspec-timeout.patch
```

This approach may have rejected hunks that require manual fixes (see "Manual Fixes" section below).

## Verifying the Installation

```bash
# Check help output
./shellspec --help | grep timeout

# Check for rejections
find . -name "*.rej"

# Test timeout functionality
./shellspec --timeout 5 spec/your_spec.sh
```

## Manual Fixes for PR Patch Rejections

If using Option 2 (PR patch), you may need to fix these rejections:

### lib/core/outputs.sh

Add this function after `shellspec_output_NOT_IMPLEMENTED` (around line 60):

```sh
shellspec_output_TIMEOUT() {
  shellspec_output_statement "tag:timeout" "note:TIMEOUT" "fail:y" \
    "timeout:$1" \
    "failure_message:${SHELLSPEC_LINENO:+<$SHELLSPEC_LINENO>}Test exceeded timeout" \
    "message:Test exceeded timeout of $1 seconds"
}
```

### lib/core/dsl.sh

The timeout execution logic needs to be added to the `shellspec_example` function. See the `.rej` file for the complete code.

**IMPORTANT:** Use `shellspec_rm -f` instead of `rm -f` for timeout file cleanup.

## Known Bug Fixes (Already Included in Patches)

These fixes are critical for the timeout feature to work:

### 1. Watchdog PATH Restoration

The watchdog script (`libexec/shellspec-timeout-watchdog.sh`) must restore `SHELLSPEC_PATH`:

```sh
# At the top of the watchdog script, after set -eu
if [ "${SHELLSPEC_PATH:-}" ]; then
  PATH="$SHELLSPEC_PATH"
  export PATH
fi
```

### 2. Use shellspec_rm for Cleanup

In `lib/core/dsl.sh`, use `shellspec_rm -f` instead of `rm -f`:

```sh
# Signal watchdog to stop
shellspec_rm -f "$SHELLSPEC_TIMEOUT_SIGNAL_FILE"
# ...
shellspec_rm -f "$SHELLSPEC_TIMEOUT_RESULT_FILE"
```

## Expected Rejections (Harmless)

The following may be rejected but don't affect timeout functionality:

| File            | Reason               | Impact           |
| --------------- | -------------------- | ---------------- |
| `package.json`  | Version bump         | None - cosmetic  |
| `shellspec`     | Version bump         | None - cosmetic  |
| `bin/shellspec` | Various improvements | None for timeout |

## Rolling Back

```bash
# Revert all changes
patch -R -p1 < timeout.patch
rm timeout.patch
```

## Troubleshooting

### Tests hang instead of timing out

1. Check if watchdog is executable: `chmod +x libexec/shellspec-timeout-watchdog.sh`
2. Verify PATH restoration code is present in watchdog
3. Check if `SHELLSPEC_PATH` environment variable is set

### "rm: command not found" or "sleep: command not found"

The PATH restoration fix wasn't applied. Ensure:
1. `libexec/shellspec-timeout-watchdog.sh` has the SHELLSPEC_PATH restoration
2. `lib/core/dsl.sh` uses `shellspec_rm -f`

### TIMEOUT message not displayed

Add the `shellspec_output_TIMEOUT` function to `lib/core/outputs.sh` (see Manual Fixes section).

## Generating Your Own Patch

To create a patch between two release versions:

```bash
# Download old and new versions
mkdir -p /tmp/patch-gen/{old,new}

# Extract 0.28.1
curl -sL https://github.com/shellspec/shellspec/archive/refs/tags/0.28.1.tar.gz | \
  tar -xzf - -C /tmp/patch-gen/old --strip-components=1

# Clone/extract new version to /tmp/patch-gen/new

# Generate patch
diff -ruN /tmp/patch-gen/old /tmp/patch-gen/new > my-patch.patch
```
